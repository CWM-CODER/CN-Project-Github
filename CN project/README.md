# Data Link Layer Protocol Simulation Suite
### CSMA/CD (Non-Persistent) + Hamming Codes (SEC) + Go-Back-N Flow Control + PyShark Packet Sniffer

A comprehensive simulation of the Data Link Layer (Layer 2) of the OSI model implemented in **C++14** and **Python 3**, featuring live network socket communication over loopback (`127.0.0.1`), binary frame serialization, and packet inspection using **PyShark**.

---

## 🚀 Quick Start (1-Click Run)

### Option 1: Automated Run (Builds C++, Runs Simulation, and Launches PyShark Sniffer)
Double-click or run from command prompt:
```cmd
run_all.bat
```

### Option 2: Manual C++ Build & Run
```cmd
g++ -std=c++14 -O2 src/main.cpp src/hamming.cpp src/csma_cd.cpp src/go_back_n.cpp src/udp_socket.cpp src/node.cpp -o dll_sim.exe -lws2_32
.\dll_sim.exe
```

### Option 3: PyShark Protocol Sniffer & Dissector
After running the simulation (which writes `capture.pcap`):
```cmd
python sniffer/pyshark_sniffer.py capture.pcap
```

### Option 4: Pure Python Reference Simulation
```cmd
python python_sim/dll_sim.py
python python_sim/test_hamming.py
```
